# Documentation

## Backend

- Framework: Flask
- Entry points: `run.py`, `backend/app.py`
- Main modules: `backend/routes/`, `backend/models.py`, `backend/security.py`

## Frontend

- Framework: React + TypeScript (Vite)
- Entry points: `frontend/src/main.tsx`, `frontend/src/App.tsx`

## Data

- Default data root: `data/`
- Important folders: `data/vcf/`, `data/variant_uploads/`

## Scripts

- `run.sh`: setup and run on Unix-like systems
- `run_windows.ps1`: setup and run on Windows

## Tests

- Backend tests are under `test/`
- Frontend tests are under `frontend/src/__tests__/`
